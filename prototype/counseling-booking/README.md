# 여백 상담실 — 로컬 1:1 상담 예약 프로토타입

연구 문서에서 확정된 공통 도메인(1:1 상담 예약)으로 만든 로컬 기능 확인용 웹 프로토타입입니다. 연구용 baseline harness 및 research 입력과 분리되어 있습니다.

## 실행

프로젝트 루트에서 다음 한 줄을 실행합니다.

    python3 prototype/counseling-booking/server.py

브라우저에서 http://127.0.0.1:8765 를 열면 됩니다. 중지할 때는 실행 중인 터미널에서 Ctrl-C를 누릅니다. 첫 실행 때 샘플 일정과 SQLite 데이터베이스를 생성하며, 다음 실행에도 예약 데이터가 유지됩니다.

임시 데이터베이스나 다른 포트를 쓰려면 다음처럼 실행합니다.

    python3 prototype/counseling-booking/server.py --port 8766 --db /tmp/counseling-demo.sqlite3

## 동작 흐름

- 고객: 상담자와 날짜 선택 → 비어 있는 시간 선택 → 이름·이메일 입력 → 즉시 예약 확정 → 예약번호 발급
- 고객: 예약번호와 이메일로 예약 조회 → 예약 취소
- 상담 일정 담당: 상담자의 가능 시간 열기·닫기 → 날짜별 예약 일정 확인
- 서버: SQLite 영속 저장, 예약 시간 중복 방지, 이미 지난 시간 거부, 잘못된 입력과 충돌에 한국어 오류 반환

샘플 상담자와 다음 주중 시간대는 첫 시작 시 데이터베이스에 생성됩니다. 예약을 취소하면 그 시간은 다시 선택할 수 있습니다.

## 프로토타입에서 임시로 둔 결정

설계 카드의 세부 내용은 아직 승인되지 않았으므로, 아래 선택은 작동 가능한 데모를 위한 가정입니다.

- 샘플 상담자 2명과 표시용 상담 유형 2개
- 상담 30분, 샘플 가능 시간은 평일 10시·11시·14시·15시·16시
- 시간 기준은 Asia/Seoul(KST)
- 예약 제출 즉시 CONFIRMED로 확정
- 예약자는 이름과 이메일만 입력. 상담 내용·건강 정보·상담 메모는 수집하지 않음
- 조회와 취소에는 예약번호와 이메일 사용. 취소 cutoff, 로그인, 재예약, 결제, 알림은 미구현
- 상담 일정 관리 화면은 시연을 위해 인증 없음. 서버는 기본값으로 127.0.0.1에만 바인딩

이 가정들은 docs/00의 미결정 사항을 확정하거나 research의 brief·condition·평가 입력으로 승격하지 않습니다. 실험에 쓰기 전에는 설계 카드 검토로 결정하고, 공통 brief 및 acceptance criteria에 별도로 반영해야 합니다.

## 데이터와 사용 경계

기본 SQLite 파일은 prototype/counseling-booking/data/bookings.sqlite3 에 생성됩니다. 이름과 이메일은 로컬 데모 데이터베이스에 저장됩니다. 테스트 데이터만 입력하고, 실제 고객정보를 넣거나 이 서버를 외부 네트워크에 공개하지 마세요. 초기 상태로 되돌리려면 서버를 중지한 뒤 데이터베이스 파일을 지우고 다시 실행합니다.

현재 외부 서비스, 로그인, 이메일/SMS 전송, 결제 연동은 없습니다. 이 결과물은 시연용 프로토타입이며 운영 서비스로 배포할 보안·개인정보 정책을 갖추지 않았습니다.
