# Condition 1: Generic Architecture Blueprint

In this condition, the Designer stage must generate a structured architectural overview of the system before any code is written.

## Designer Instructions
1. Break down the system into logical components, actors, and user flows.
2. Identify the main domain entities and their high-level relationships.
3. List the high-level operational states for the primary domain entities.
4. Provide a standard, clean architectural guide for the Coder stage without enforcing rigid type signatures or low-level implementation details.
