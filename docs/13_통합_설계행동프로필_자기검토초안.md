# 내 설계 행동 프로필 — 통합 자기검토 초안

**상태: 본인 검토 전 / 실험 입력 승인 전**  
**대상: 프로젝트 소유자 1명**  
**범위: 사용자가 제공한 Aside profile 자료와 접근 가능한 Codex·ChatGPT 작업 대화의 교차 검토**

이 문서는 Aside에서 가져온 원본 검토 초안과 JSON을 보존하면서, 앞서 작성한 Codex·ChatGPT 기반 프로필 후보를 합쳐 한 사람이 확인할 수 있게 만든 통합 검토판이다. 원본별 출처와 한계는 아래 출처 자료를 참조한다.

## 출처와 한계

- Aside 근거는 사용자가 제공한 09_내_설계행동프로필_검토초안.md와 10_내_설계행동프로필_입력초안.json의 요약·근거 ID를 사용했다. Aside 세션이나 memory 파일을 이번 작업에서 직접 열어 검증하지 않았다.
- Codex·ChatGPT 근거는 관련 연구 harness, 코드 흐름 학습, 제품 동작 확인 대화 중 접근 가능한 일부를 검토했다. 모든 대화를 전수 검색한 표본은 아니다.
- 근거의 공통 패턴을 요약할 때 사용자 메시지와 사용자가 제공한 Aside 요약만 사용했다. assistant의 제안은 사용자 행동 근거로 세지 않았다.
- 빈도는 전체 활동에서의 발생률이 아니라, 출처 자료에서 확인된 작업 맥락 수와 반복성이다.
- 성격, 능력, 동기, 심리적 특성을 추정하지 않는다. 부작용은 프로필을 에이전트에 적용할 때 확인할 위험 가설이지, 사용자에게 관찰된 결함이 아니다.
- 본인이 이 요약을 요청한 것은 프로필 초안을 검토·작성할 허가다. 정식 연구 참여 동의, 원문·파생 자료의 보관 기간, 폐기 절차, 외부 공개·학습 사용은 별도로 결정해야 한다.

## 아직 확정하지 않은 후보

- 코드 흐름을 diff보다 항상 우선한다는 일반 습관: Aside 자료도 한 세션의 자기보고는 단독 근거로 확정하지 않았다. 별도 맥락에서 반복되기 전까지 독립 프로필 지침으로 쓰지 않는다.
- 세부 검토를 선호한다는 성격 라벨: 관찰 가능한 요청으로만 기술하며 완벽주의·꼼꼼함·위험회피 등의 성격 추정은 하지 않는다.
- 반복 대화 세션 선호: ChatGPT에서 지속형 session을 요청한 자료는 있으나, 여러 작업 맥락의 반복 증거가 부족해 핵심 프로필에 넣지 않는다.

## 조건에 전달할 적용 초안

본인 확인 전에는 조건 파일이나 run 입력에 넣지 않는다.

### T1-C: 직접 적용

- 먼저 대상 저장소·사용자 흐름·명시 범위와 현재 확인된 사실을 정리한다.
- 요구, 업무 규칙, 가정, 미정 질문을 분리하고, 각 설계 결정을 근거와 연결한다.
- 핵심 흐름의 실제 동작을 확인하고, 실행한 검증과 미검증 범위를 보고한다.
- 설계·구현 품질과 token·latency·tool 비용을 별도로 기록한다.
- 확인 항목을 모두 기능 요구로 바꾸거나 모든 경로를 과도하게 추적하는 현상이 있는지 관찰한다.

### T1-D: 보정 적용

같은 승인 profile을 유지하되 발견한 항목을 다음 중 하나로 분류한다.

- implement_now: 승인 범위이며 현재 구현에 필요
- clarify: 결과가 달라지는 사용자 결정이 필요
- defer: 가치가 있지만 현재 brief에서 후속으로 미뤄도 됨
- out_of_scope: 현재 과제·실험 범위 밖

검증은 핵심 흐름부터 수행한다. 모든 가능한 예외를 제품 기능으로 늘리지 않고, 확인하지 않은 동작은 완료로 보고하지 않는다.

## Track 1 사용 경계

- 참여자 한 명의 프로필이므로 결과는 이 사람, 승인된 과제, 모델과 환경에 한정된 탐색적 단일 사례다. 개발자 일반으로 일반화하지 않는다.
- 본인이 각 행동의 근거·빈도·맥락·신뢰도·기대 이점·부작용 가설을 확인한 뒤 승인 버전과 hash를 고정한다.
- 추출 규칙은 고정하고 동일한 승인 프로필을 T1-C와 T1-D에 사용한다. 두 조건 사이에서는 적용·보정 정책만 비교한다.
- Aside의 원본 검토 초안과 JSON, 이전 Codex·ChatGPT 초안은 provenance 자료로 보존한다. 이 통합 문서도 현재 미검토이며, 실행 입력은 아니다.
- 원문 대화 ID와 발췌문은 실험 입력·blind evaluator 자료로 내보내지 않는다. 보관 기간·폐기 정책을 protocol에서 먼저 정한다.

## 본인 검토

각 항목에 대해 행동 설명, 근거, 맥락 수, 신뢰도, 기대 이점, 부작용 가설을 확인하고 필요하면 수정·제외한다. 모든 항목을 확인한 뒤에도 정식 실험 참여 동의와 자료 보관·폐기 결정을 별도로 남긴다.
