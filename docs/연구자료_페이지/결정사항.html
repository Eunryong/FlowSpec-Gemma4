결정 요약

확정된 연구 방향과 미정 항목.

확정됨
  • Track 1: 개발자 설계 사고 프로필 + 장단점 보정
  • Track 2: Revision-aware Design, 즉 변경을 고려한 설계
  • 두 연구는 독립적으로 진행
  • 공통 난이도는 L2
  • 공통 도메인은 1:1 상담 예약

L2를 여기서 뜻하는 것

단순 CRUD보다 흐름과 상태가 있고, 실제 운영 서비스보다는 작게 제한해. 주요 사용자 흐름, 저장할 데이터, 상태 전이, 모듈 경계와 테스트 가능한 결과가 있어야 해.

아직 미정

  • 상담 분야와 예약 단계에서 저장할 정보
  • 상담자 한 명/여러 명 및 상담자 선택·배정 방식
  • 예약 즉시 확정인지 승인 대기인지
  • 취소·변경 정책, 시간 기준, 로그인 여부
  • 최종 v1 요구사항과 숨은 변경, 평가 기준
대체된 결정작업 스케줄러는 현재 도메인이 아니야. 그때 승인한 로컬 시뮬레이션과 run_at 결정은 상담 예약 서비스에 자동 적용하지 않아.
