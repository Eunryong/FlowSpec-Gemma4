Track 1 프로필

개발자 설계 사고 프로필 입력 조건.

Track 1 입력 목적개발자 설계 검토 행동의 프로필을 주입하고 보정 효과를 비교해. 현재 실제 프로필은 채우지 않았어.

조건 초안

T1-A · 일반 기준 조건개발자 프로필이나 추가 검토 절차 없이 일반 설계를 요청한다.
T1-B · 공통 검토 체크리스트모든 조건에 동일한 예외·실패 상황 체크리스트를 적용한다.
T1-C · 보정 없는 프로필 적용프로필 경향을 그대로 반영하고 부작용은 별도로 보정하지 않는다.
T1-D · 장점 활용 + 부작용 보정근거가 확인된 강점만 활용한다. 발견 사항은 지금 구현·확인 질문·보류·범위 제외로 분류하고, 모든 가정을 기능으로 만들지 않는다.

프로필에 필요한 정보

  • 행동 패턴 설명과 관찰 근거 ID
  • 발생 빈도, 관찰된 작업 상황, 신뢰도
  • 개발자 확인 여부
  • 기대되는 장점과 가능한 부작용

프로필 사용 원칙

  • 근거가 없는 프로필 값은 추측해 채우지 않는다.
  • 반복된 관찰 근거와 개발자 검토 전에는 확정 연구에 사용하지 않는다.
  • 프로필 정보를 숨은 제품 요구사항으로 취급하지 않는다.
  • 개인화 효과를 분리할 수 있도록 모든 사람에게 동일한 일반 검토 조건을 둔다.
현재 상태프로필 근거, 참여자 동의 절차, 평가 기준이 정해지지 않아 실험 준비 전이야.
