사용 방법

파일을 어떻게 결합하고 실행하는지.

실험 입력 준비 순서

  1. 설계 카드에서 실제 v1 요구를 승인하고, 가정·미정·제외를 나눈다.
  2. 승인한 요구만 공통 초기요구 템플릿에 옮긴다.
  3. 공통 입력에 Track 1 또는 Track 2 조건 파일 하나만 결합한다.
  4. 각 조건은 새 AI 대화에서 실행하고, 입력·출력·모델 설정을 보관한다.
  5. Track 2는 초기 설계를 저장한 후에만 후속 변경 하나를 공개한다.

현재 실행 가능 여부아니야. v1 요구, 프로필 근거, 숨은 변경, gold test가 모두 미확정이야.
