- **코드 흐름을 diff보다 우선한다는 안정적 습관:** 2026-09-29에 흐름 파악의 어려움을 직접 언급한 기록은 있지만, 반복 관찰 근거가 아직 부족해 독립 프로필 항목으로 확정하지 않았습니다. 관련 Codex 기록을 제공받거나 다른 Aside 작업에서 반복 확인한 뒤 재검토할 수 있습니다.
- **성격 추정:** 완벽주의, 꼼꼼함, 위험회피 같은 성격 라벨은 사용하지 않았습니다.

## 연구에 사용하기 전 절차

1. 참여자 동의, 자료 출처, 개인정보 보관·폐기 규칙을 먼저 확정합니다. 현재 구체 규칙은 미정입니다.
2. 반복 관찰된 행동만 근거로 남기며, 성격 추정이나 단일 사례를 사실처럼 쓰지 않습니다.
3. 참여자가 각 항목의 근거·빈도·맥락·신뢰도와 예상 장점·부작용을 확인·수정합니다.
4. 승인한 동일 프로필을 Track 1의 해당 비교 조건에 적용합니다. 프로필을 추출하는 방법과 프로필 사용 효과를 한 실험에서 동시에 바꾸지 않습니다.
5. 조건마다 새 Designer/Coder 세션에서 같은 공통 brief를 사용하고, blind evaluation으로 결과를 비교합니다.
